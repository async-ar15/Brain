# Mock Interview 2 — Revision Sheet

---

## Technical Communication Checklist

Review this checklist before every mock and real interview.

### 1. Requirements Gathering
- [ ] Did I ask about the size of the input?
- [ ] Did I ask if the array/string is sorted?
- [ ] Did I ask what to return if no solution exists?
- [ ] Did I ask about memory constraints?

### 2. Algorithmic Design
- [ ] Did I state the brute force solution out loud?
- [ ] Did I state the optimal time and space complexity before coding?
- [ ] Did the interviewer explicitly say "Yes, that sounds good, you can code that"? (If not, don't start coding!)

### 3. Coding Execution
- [ ] Are my variable names descriptive? (e.g., `left` and `right` instead of `i` and `j`, `maxProfit` instead of `m`).
- [ ] Did I modularize my code? (e.g., pulling a BFS traversal into its own helper function rather than nesting it 4 levels deep).
- [ ] Did I handle base cases at the very top of the function?

### 4. Verification
- [ ] Did I walk through a test case step-by-step?
- [ ] Did I check the boundaries (e.g., index 0, index `array.length - 1`)?
- [ ] Did I verify the time and space complexity matches what I promised?
